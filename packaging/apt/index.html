wbanish

Hides the mouse cursor while typing on Wayland, like xbanish. Source and documentation: github.com/ksobitov/wbanish.

Install on Debian or Ubuntu

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/wbanish.asc https://ksobitov.github.io/wbanish/wbanish.asc
sudo tee /etc/apt/sources.list.d/wbanish.sources <<EOF
Types: deb
URIs: https://ksobitov.github.io/wbanish
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/wbanish.asc
EOF
sudo apt update
sudo apt install wbanish

wbanish reads keyboards from /dev/input, so add yourself to the input group and log in again:

sudo usermod -aG input $USER
