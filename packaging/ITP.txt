  Description     : hide the mouse cursor while typing on Wayland

wbanish hides the mouse cursor when a key is pressed, and shows it again
when the mouse is moved, a button is pressed or the wheel is scrolled. It
is a Wayland counterpart of xbanish.

On GNOME it hides the cursor through the GNOME Shell extension that comes
with it; elsewhere it needs a compositor that implements the wlr-layer-shell
protocol, such as labwc, river, Wayfire or KDE Plasma. Keyboards are read
from /dev/input, so the user has to be in the "input" group.

Debian already has xbanish, unclutter and unclutter-xfixes, but all three
only work on X11. A few compositors (Sway, Hyprland, niri, Plasma 6.2+) can
hide the cursor while typing themselves; wbanish covers the others,
including GNOME, which has no such setting.

All build dependencies are already in unstable. I am the upstream author
and plan to maintain the package within the Debian Rust Team
(debcargo-conf). I will need a sponsor for the upload.
